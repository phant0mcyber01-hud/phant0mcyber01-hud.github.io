## 🚀 Как выложить на GitHub Pages:

1. Создай на GitHub репозиторий с точным именем:
   `phant0mcyber01-hud.github.io`
   *(публичный, без README)*

2. В терминале в папке этого проекта выполни:
   ```bash
   git init
   git add .
   git commit -m "feat: initial engineering portfolio showcase"
   git branch -M main
   git remote add origin https://github.com/phant0mcyber01-hud/phant0mcyber01-hud.github.io.git
   git push -u origin main
   ```

3. Сайт автоматически станет доступен по адресу:
   👉 **`https://phant0mcyber01-hud.github.io`**

## 📌 Правило обновления (Железный регламент):
При добавлении каждого нового проекта в канал:
1. Добавляем карточку проекта в `index.html` и объект в `script.js`.
2. Делаем `git commit -am "feat: add new project"` и `git push`.
3. Ссылка в Telegram канале всегда остаётся актуальной!
